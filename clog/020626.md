# Clog — 2026-06-02

## Autopilot (active collection) — branch `autopilot`
User wants an active data-collection mode: auto-scroll + periodically switch to trending topics,
dwell per topic, repeat. Decided (eyes-open) on **full autopilot** despite the ToS/account-risk
posture shift from the passive v0.1. Built on a branch so `main` stays passive until we decide to
merge (which will require rewriting the README's "passive / not a bulk crawler" claims).

**Design — resumable state machine.** Switching topics is a real navigation, so the content script
re-injects each time; runtime state lives in `chrome.storage.local` (`autopilot_run`) and the driver
resumes on load. Bound to one tab id (via a `autopilot_whoami` round-trip to the SW) so a run can't
hijack the user's other x.com tabs. Capture pipeline (injected/content/background) **untouched** —
autopilot just drives the feed so the passive hook sees more.

**Files:**
- `autopilot.js` (new) — isolated-world, `document_idle`. Scroll engine (jittered cadence, occasional
  long pause, end-of-feed detection), topic queue + dwell cycling, hard caps (max topics + session
  minutes), stop-on-blocked-page (login/verify/suspended), on-page Stop badge (popup closes on nav).
- `manifest.json` — 3rd content script entry (no new permissions; reuses host_permissions for
  tab messaging).
- `background.js` — `autopilot_whoami` → returns `sender.tab.id`.
- `popup.html` / `popup.js` — Autopilot panel: mode (Trending / Manual list / Current page),
  dwell, cadence, max topics, session cap, loop; Start/Stop; live status. Conservative defaults
  (90s dwell, 2s cadence, 8 topics, 20-min cap).

**Trends source:** reads `[data-testid="trend"]` off `/explore` (DOM), builds `/search?q=…&f=live`
URLs. Markup-dependent → flagged as a maintenance point like the GraphQL extractor. Manual mode
(paste hashtags/queries) is the reproducible alternative.

**Verified:** 6/6 JS syntax-clean; manifest valid; extractor 8/8 still green (core unchanged).
**Not yet verified (needs a browser):** the live scroll/navigate loop, trend-DOM reading, the
