## 16:25 — Core code written
- `injected.js` MAIN-world hook, `content.js` bridge, `extractor.js` walk, `background.js` SW.
- Decision: classic `importScripts` SW (not ES module) so `extractor.js` doubles as a
  Node-testable CommonJS module.
- Added `unlimitedStorage` permission — a research tool can accumulate thousands of posts and
  the default ~10MB `storage.local` quota would silently drop writes (data loss). Non-warned perm.
- background.js adds a **serialized promise queue** around read-modify-write: the spec flags the
  concurrency race as "harmless dupes", but it can actually LOSE tweets (last-write-wins clobber)
  under rapid scroll. Serializing fixes it; still reads fresh from storage so SW teardown is safe.
- RT/quote decision: capture both wrapper + inner (faithful "feed as experienced"); resolve RT
  wrapper text to the embedded original's full text (no truncated "RT @…" garbage). Documented.
